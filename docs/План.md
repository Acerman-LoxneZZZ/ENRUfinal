# План сборки «Раскладки»

Используем исходный мастер-промпт как спецификацию. Результат — переносимый Raskladka.exe для Windows с русскоязычной WPF-панелью.

1. Core — двуслойная таблица физических клавиш, определение направления, файл настроек, транзакционное назначение глобальной клавиши. Проверить неоднозначность, знаки, регистр, переносы и эмодзи.
2. Integration — по нажатию сочетания определить выделение или слово у курсора, проверить доступность и фокус, сделать одну отменяемую замену и подтвердить её результат. Для слова сохранить положение курсора.
3. UI — панель, назначение сочетания, единый список настроек с прокруткой, прерываемые переходы, системный контраст и минимальное движение.
4. Приложение — связать глобальную команду, окно, настройки и редакторы. Добавить трей, единственный экземпляр, восстановление позиции и освобождение ресурсов.
5. Собрать и проверить запуск, реальный Блокнот, браузерный редактор и Electron. Сохранить короткую запись и указать результаты отдельно для выделения, слова у курсора и отмены.
