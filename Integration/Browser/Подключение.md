# Поля Chrome и Edge

1. Разместите папку сборки там, откуда будете запускать утилиту.
2. В папке сборки откройте PowerShell и выполните команду ниже. Она регистрирует локальный обработчик Native Messaging в настройках текущего пользователя.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Browser\Register.ps1
   ```

3. Откройте в Edge `edge://extensions` или в Chrome `chrome://extensions`, включите «Режим разработчика», выберите «Загрузить распакованное расширение» и укажите папку `Browser\Extension`. Для работы на локальной HTML-странице дополнительно включите «Разрешить открывать локальные файлы по ссылкам» в карточке расширения.
4. Обновите вкладку с текстовым полем. Запустите «Раскладку» и нажмите своё сочетание в обычном поле ввода или многострочном поле. Исправится слово у курсора. Чтобы исправить фрагмент целиком, сначала выделите его. Ctrl+Z отменяет исправление.

При обновлении уже установленного расширения перезагрузите его на странице расширений, затем обновите вкладку. По нажатию сочетания выбранный фрагмент или слово передаётся локальной утилите через именованный канал Windows. Расширенные редакторы на базе contenteditable, страницы настроек браузера и защищённые поля исключены. Доступ к сайтам можно ограничить в карточке расширения.

После переноса папки сборки повторите регистрацию и выберите новое расположение распакованного расширения. Для удаления сначала удалите расширение через браузер, затем выполните команду из папки сборки.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Browser\Register.ps1 -Remove
```
